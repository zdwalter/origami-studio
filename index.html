    使用说明

    三种模式

    3D 仿真：选择左侧图案（或导入 SVG/FOLD 折痕图），拖动底部“折叠程度”滑块，基于杆-铰链（bar & hinge）动力学模型实时计算纸张形态。负值会将山折与谷折互换。

    自碰撞：默认开启，纸张层与层之间会互相顶住、不会穿过彼此；“纸张厚度”滑块控制层间距。想看纸被“顶开”的样子可以关掉它。

    分步折叠：多条折痕可以分先后（例如三折页先折一道再折另一道），拖动滑块时会按顺序逐道折完，纸片不会同时往同一处扫过去。

    折痕设计：在 2D 折痕图编辑器中绘制山折（红）、谷折（蓝）、平面线、自由铰链、剪切线，右侧实时 3D 预览；编辑器会检查每个内部顶点是否满足平折条件。

    分步折叠：像折真纸一样一步步折：画折线、点到点、边到边，可翻面/旋转，跟随教程完成纸飞机、纸船等作品，并可把折痕发送到 3D 仿真。

    修改这一步：折到某一步（或在右侧「步骤」里点它）后，下方「修改这一步」可以调这一折的折角（0–180°，也可用「折平 180° / 垂直 90° / 浅折 60°」快捷按钮）。折角会写进这一步和它的折痕（`foldAngle`），并影响 3D 展开展示与发送到 3D 的折叠树；步骤列表里带折角的步骤会显示角度徽标。

    选纸：分步折叠工具栏「纸张」可选正方形 1:1 或 A4（1:√2），换纸会按所选尺寸新建一张纸；载入教程时会自动切到该教程用的纸（滑翔机是 A4 比例）。折痕设计里也有「新建正方形纸 / 新建 A4 比例纸 / 自定义比例」。

    3D 展开展示：折完的作品（如纸飞机、滑翔机）点工具栏「3D 展开展示」，会把折好的成品按三维姿态展开（机翼张开、机身撑起），可以拖动旋转看各个角度；再点一次回到平面。

    分步成品进 3D：在分步折叠里点「折痕 → 3D 仿真」，3D 模型是直接从折叠树生成的（不是从折痕图反推），所以多层重叠也不会算歪；拖动「折叠程度」就能看着纸一道一道折起来，展开 0% 是整张纸、100% 是成品。这种模型是"姿态回放"，不走动力学（自碰撞、拖拽对它不生效）。

    折角进 3D：折痕记录的 `foldAngle` 会直接作为 3D 仿真的目标折角——比如机翼那两道记的是 90°，3D 里就折到 90°，而不是一律折平到 180°。只是"压了痕再展开"的折痕（angle=0）仍保持 0，不会因为记录过折角就折起来。

    折痕的顺序与折角：每条折痕都记着「第几步折出来的」（stage）和「当时折了多少度」（foldAngle）。平面视图默认在折痕上标步骤号（工具栏「步骤号」可关）；把折痕发到 3D 仿真后，3D 会按步骤顺序一道一道折，而不是所有折痕同时折。

    展开复原 / 打开上一折：折过之后点「展开复原」，纸会重新铺平，但折痕全部留在纸上（可以作为折痕图导出、发送到 3D 仿真）；「打开上一折」只把最近折的那一下打开，折痕同样保留。两个操作都记成一步，可以撤销。

    折角：工具栏的「折角」可以选择这一折折多少度——180° 是常规的折平，90° 是折到与纸面垂直，60° 是只折 60°。折角会记在这一步里，成品用「3D 展开展示」按这个角度展开；平面视图仍按折平显示（层序和折痕计算需要平面状态）。

    3D 视图操作

    • 左键拖动：旋转　右键 / Shift + 拖动：平移　滚轮 / 双指：缩放
    • “拖拽”模式下左键可直接抓取纸面上的点拉扯纸张
    • 空格 播放/暂停 F 适配 R 重置 0137 视角 W 网格 H 应变 G 拖拽

    折痕设计快捷键

    • L 画线 S 选择 E 擦除 B 角平分 P 中垂线 R 射线
    • 1-5 或 M/V/F/U/C 切换线型　Shift 22.5° 角度约束　Esc 取消
    • Ctrl+Z 撤销 Ctrl+Shift+Z 重做 Del 删除 Ctrl+A 全选

    平折定理

    前川定理（Maekawa）：平折顶点处山折与谷折数量相差 2，即 |M − V| = 2。

    川崎定理（Kawasaki）：平折顶点周围相间的扇形角之和均为 180°。

    编辑器中绿色圆圈表示该顶点满足两条定理，红色表示不满足（鼠标悬停查看误差）。局部可平折并不保证整体可平折（还需层序不自交）。

    源码 · 自己改

    全部源码在 GitHub：github.com/zdwalter/origami-studio。纯静态 HTML/CSS/JS，没有构建依赖，fork 下来直接改 js/ 下的文件、刷新页面即可。

    • js/stepfold.js 分步折叠引擎 + 折叠树转 3D 模型
    • js/stepmodels.js 教程步骤数据（要加新教程就改这里）
    • js/patterns.js 图案库折痕数据
    • js/solver.js 杆-铰链动力学求解器　js/renderer.js WebGL 渲染
    • python3 tools/build.py 打单文件版（dist/origami-studio.html），双击即可离线用

    欢迎提 issue / PR；也可以直接 fork 一份改成自己的作品集。

    文件格式

    SVG 颜色约定（与 Origami Simulator 兼容）：红色 = 山折、蓝色 = 谷折、黑色 = 边界、绿色 = 剪切、黄色 = 平面线、品红 = 未指定；线条透明度表示目标折角（1 = 180°）。也支持 FOLD 格式的读写，及 OBJ / STL 模型导出。

    仿真为简化物理模型：自碰撞是近似的软约束；折痕图的折角设定若互相矛盾（如把两种折痕设成同一折角），纸会靠拉伸去凑，看起来就会互相穿过。

    吉村折的菱形格里，水平折痕与对角折痕的折角必须按“可折叠族”配套（水平 15° 时对角约 38°）；它的刚性折叠范围很小，水平折角超过 20–25° 面板就只能互相穿过，所以参数上限卡在 20°。
