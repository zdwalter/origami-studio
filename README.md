# 纸境 · 折纸仿真平台（Origami Studio）

纯 HTML/CSS/JavaScript 编写的折纸仿真平台。没有依赖，不用构建，也不需要联网。

**线上地址：<https://game.sopher.cool/origami/index.html>**（单文件版 <https://game.sopher.cool/origami/dist/origami-studio.html>）

- **直接使用**：用现代浏览器（Chrome / Edge / Firefox / Safari）打开 `index.html`。
- **单文件版**：`dist/origami-studio.html` 包含全部代码，可以单独发给别人。修改源码后运行 `python3 tools/build.py` 重新生成。
- **部署**：`./deploy/deploy.sh` 一条命令发到 game.sopher.cool（详见 [deploy/README.md](deploy/README.md)）。

## 三种工作模式

### 1. 3D 仿真
- 使用杆-铰链（bar & hinge）动力学模型，参考 Ghassaei 等人 2018 年的论文：每条网格边都是轴向弹簧，每条折痕都是带目标折角的旋转铰链，面板对角线作为保持平直的铰链，用显式积分加阻尼求解。
- 拖动“折叠程度”滑块可在 −100% 到 100% 之间调节，负值表示山折与谷折互换；也可以点击播放按钮，让模型在展开和折叠之间往复演示。
- 可以实时调整轴向刚度、折痕刚度、面板刚度、阻尼和折叠速度。
- **拖拽模式**：直接用鼠标抓住纸面上的点拉扯纸张。
- **自碰撞**：默认开启，纸张不会穿过自己，层与层之间会留出“纸张厚度”（可在右侧调 1–20‰ 或关掉对比）。折痕图本身错了（例如把两种折痕的折角设成同一个值）时，纸只能靠拉伸去凑，看起来就会互相穿过——这类情况现在能被看出来。
- **分步折叠（3D）**：折痕可以带“阶段”编号，滑块会把各阶段依次折完（三折页就是先折一道、再折另一道），避免两片纸同时往同一个地方扫过去而互相穿过。
- **叠层深度偏置**：折叠树模型的多层几何完全贴合（不做位置偏移），重叠层的先后由渲染器顶点属性 `aBias`（按层号）决定，避免共面 z-fighting。
- **折叠树直接生成 3D（buildPoseModel）**：分步折叠的「折痕 → 3D 仿真」不再走"折痕图 → 求解器"（多层折痕图对求解器是矛盾的），而是把每个纸片单独建节点、按折叠树重放三维姿态；`setFoldPercent(fp)` 按 stage ramp 逐道折。返回对象带求解器接口（positions/step/bounds/...），可直接给 renderer 用。
- **3D 目标角 = foldAngle**：`cp.buildMesh` 建 hinge 时，折痕若带 `foldAngle` 就用它作为目标角（angle=0 的压痕仍为 0）；配合 `stage`，3D 仿真按步骤顺序折到各自的角度。
- **折痕元数据**：每条折痕带 `stage`（第几步折出来的，1 基）和 `foldAngle`（这一折当时折多少度，默认 180°）。展开复原后仍然保留；导出折痕图时随 lines 一起走。3D 仿真按 `stage` 顺序折叠（`solver.stageScale` 逐级 ramp）。
- **展开复原（unfoldAll）**：把折好的几何恢复成整张平纸，折痕全部保留（角度归 0），可导出成折痕图；另有 `unfold` 只还原最近一次折叠。
- **折角（fold angle）**：每一步折叠都可以指定折多少度（`op.angle`，默认 180° = 折平）。分步折叠工具栏的「折角」下拉选择 180/160/135/120/90/60/45；折角只影响三维展示与导出数据，平面层序计算仍按 180° 折平以保证稳定。
- **3D 展开展示**：折完的作品可以在分步折叠里一键「3D 展开展示」——按模型自带的角度把折痕重新打开（机翼张开、机身撑起），拖动可旋转视角。实现方式是把分步折叠的成品在三维里按指定折角重放（`StepFold.threeDPose`），不经过动力学求解，所以形状精确、不会抖。
- **角度曲线（3D）**：有些图案的折痕折角不是线性缩放的关系（吉村折的菱形格：对角折角要按“可折叠族”跟着水平折角变），图纸里可以把“进度 → 折角”的表挂到折痕上，由求解器插值，保证折叠中途也是等距、不穿插。
- **显示选项**：折痕颜色（红山、蓝谷）、三角网格、**应变热力图**、地面与阴影。
- **视角**：透视、俯视、正视、侧视、仰视，另有适配视图和全屏。
- **纸张外观**：正反面颜色、预设配色、棋盘格或波点纹样、纸纹。
- 状态面板显示顶点数和三角形数、折痕统计、平均折角误差、最大应变、每帧迭代次数和帧率。

### 2. 折痕设计（2D 编辑器 + 实时 3D 预览）
- **工具**：画线、选择（框选，拖动端点或线段，Alt 拖动为复制）、擦除、改类型、角平分线、中垂线、垂线、射线（延长到遇到的折痕或纸边）、镜像、平移。
- **线型**：山折、谷折、平面线、自由铰链、剪切，并可设置每条线的目标折角。
- **吸附**：网格点（方格或三角网格）、顶点、中点、交点、线上任意点；按住 Shift 时角度约束为 22.5° 的倍数。
- **平折检查**：逐个检查内部顶点是否满足前川定理（Maekawa）和川崎定理（Kawasaki），绿圈表示满足，红圈表示不满足；鼠标悬停可查看误差和扇区角度。
- 支持撤销/重做（200 步）、全选、删除、山谷互换，以及新建正方形、A4 比例或自定义比例的纸张。
- 每次编辑会自动做平面化处理：在交点处打断、合并重合顶点、去除重复线段，然后重建 3D 网格。

### 3. 分步折叠
- 像折真纸一样一步一步折：
  - **折线**：拖出一条折线，再点击要翻折的一侧。
  - **点到点**：把一个点折到另一个点上。
  - **边到边**：把一条边折到另一条边上，折线为两边的角平分线。
- 可选谷折或山折，作用范围为所有层或仅顶层；还可以翻面、旋转 ±45°，以及撤销/重做。
- 折叠时用 3D 透视动画展示，并带阴影和纸张正反面颜色。翻折前会预览要动的翻片、它的落点，以及一个指示方向的箭头。
- **教程**（共 8 个）：纸飞机、**滑翔机（长方形纸）**、报纸帽、纸杯、小狗脸、东南西北、折扇、四等分练习。支持上一步/下一步、点击任意步骤跳转和自动演示。
- 滑翔机教程共 12 步（中折痕 → 两上角 → 两斜边 → 机头 → 对折 → 左右机翼各折一次），按用户校对的版本。
- 教程支持两种真实图纸里的动作：**折出折痕再展开**（第 1 步压中折痕那种）和**打开口袋**，所以像滑翔机这种「先压中折痕、再折角、折机头」的图纸可以按原样一步步做。
- “折痕 → 3D 仿真”会把折出的全部折痕（山谷方向以纸张正面为准）发送到 3D 仿真模式。

## 图案库（36 个参数化图案）

- **基础折法**：对折（谷折 / 山折）、对角折、阶梯折、四角向心折、三折页。
- **传统基本型**：正方基本型、水雷基本型、风筝基本型、鱼基本型、鹤基本型（鸟基）。
- **立体器皿**：剪折纸盒（展开图）、剪折浅托盘、Z 形折、单角折。
- **镶嵌 / 刚性折**：三浦折（Miura-ori）、吉村折、水雷镶嵌、方形扭转、斜向手风琴折、帐篷折、人字褶带。
- **曲面 / 非平折**：双曲抛物面（Hypar）、同心圆褶、Kresling 扭转筒、波纹板、螺旋卷、扭转带、波浪壳、卷角、折扇圆盘。
- **剪纸 / 立体卡**：单阶立体贺卡、双台阶立体贺卡、立体高塔、立体屋顶（小房子）、立方体展开图。

带参数的图案（列数、行数、倾斜角、目标折角、盒壁高度等）可以在右侧面板实时调整。所有标为可平折的图案都按精确几何构造，全部通过 Maekawa 和 Kawasaki 检查；带剪切线的展开图（纸盒、立体卡、立方体）会自动去掉剪下的废料。

仿真里所有折痕都带“目标折角”（0–180°），所以盒壁折 90°、屋面折 90°、平折折 180° 可以混在一张图里，滑块拉到 100% 时各自停在正确的角度上。

## 文件与数据
- **导入**：支持 SVG 折痕图、[FOLD](https://github.com/edemaine/fold) 文件和项目文件 `.json`，可点击按钮导入，也可直接把文件拖进页面。SVG 颜色约定与 Origami Simulator 相同：红为山折、蓝为谷折、黑为边界、绿为剪切、黄为平面线、品红为未指定；线条透明度表示目标折角。
- **导出**：
  - 折痕图：SVG、FOLD、PNG。
  - 折叠形态：FOLD 3D、OBJ、STL、3D 截图 PNG。
  - 项目文件，以及分享链接（折痕图压缩后写进 URL）。
- **存储**：“我的作品”保存在浏览器的 localStorage 中；当前进度、主题和仿真参数也会自动保存。

## 快捷键
- **3D 仿真**：
  - `空格` 播放/暂停，`←` / `→` 调节折叠程度。
  - `F` 适配视图，`R` 重置仿真。
  - `0` / `1` / `3` / `7` 切换视角。
  - `W` 网格，`H` 应变，`C` 折痕，`G` 拖拽。
- **折痕设计**：
  - `1`–`6` 或 `M` / `V` / `F` / `U` 切换线型，`Shift` 角度约束，`Esc` 取消当前操作。
  - `Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做，`Del` 删除，`Ctrl+A` 全选。
- **分步折叠**：`←` / `→` 上一步/下一步，`Ctrl+Z` 撤销，`Esc` 取消。
- **全局**：`Ctrl+S` 保存，`Ctrl+O` 导入，`?` 帮助。

## 代码结构
| 文件 | 作用 |
|---|---|
| `js/geom.js` | 2D/3D 向量、矩阵、裁剪、三角剖分 |
| `js/cp.js` | 折痕图模型：平面化、面提取、网格生成（剪切处复制节点）、平折验证、FOLD/SVG 读写 |
| `js/solver.js` | 杆-铰链动力学求解器，以及 OBJ / STL / FOLD 导出 |
| `js/renderer.js` | WebGL 渲染：正反面着色、纸纹、折痕线、阴影、轨道相机、射线拾取 |
| `js/patterns.js` | 参数化图案库 |
| `js/cpeditor.js` | 2D 折痕编辑器 |
| `js/stepfold.js` / `stepview.js` / `stepmodels.js` | 分步折叠的引擎、交互视图和教程 |
| `js/app.js`, `index.html`, `css/app.css` | 应用外壳 |

## 抖动（已修）
3D 仿真里有三处会造成“纸一直在抖”，现在都处理了：朝向校正的参考面会来回跳（改用面积加权的方向张量主轴，连续不跳）、折叠过程中追着变化中的纸面法向转（改成只在不折且静止时校正）、接触留下的纳米级微动让求解器永远不“睡着”（加了 25 帧静止就休眠：清零速度、停止迭代）。折完停下后纸面是真正静止的（实测每帧位移 0）。

## 局限
- 自碰撞是“顶点-三角形 + 边-边”的近似：默认开启时纸张不会互相穿过，但它是软约束，折得极深时仍可能残留少量穿插。多层紧贴的图案（吉村折菱形筒、同心圆褶）默认会自动关闭自碰撞——开着会把几十层纸顶开，反而把形状撑变形。
- 刚性面板模型无法沿闭环弯曲：同心圆褶用多边形环逼近圆弧，折起来必然起皱，属于近似图案（界面里也标了）。
- 分步折叠只支持平折操作（谷折、山折、翻面、旋转），不支持内翻折、压折、花瓣折这类需要同时移动多条折痕的操作。因此纸鹤之类的作品请在图案库里用 3D 仿真查看。
