# 部署到 game.sopher.cool

线上地址：

* **平台 <https://game.sopher.cool/origami/index.html>**
* 单文件版 <https://game.sopher.cool/origami/dist/origami-studio.html>
* 门户 <https://game.sopher.cool/>

游戏铺是一台阿里云 Ubuntu + nginx 的机器，站点根目录 `/var/www/game.sopher.cool`，
每个项目一个子目录（`zelda/`、`gilded-age/`、`tank/`、`jet/`、`kards/`、`origami/`…）。

```
deploy/
├─ deploy.sh            一条命令：传游戏 + 封面 + 更新门户卡片 + 自检
├─ patch_portal.py      幂等地把卡片插进门户首页，并把「在架 N 款」+1
├─ portal-card.html     门户卡片片段（与现有卡片同款结构）
├─ stamp_assets.py      给页面里的 js/css 引用打 ?v=<时间戳>，防浏览器旧缓存
├─ make_cover.py        由 hero.png 生成 900×506 封面
├─ hero.png             封面底图（隐藏全部界面后的 3D 视图截图）
├─ origami-cover.jpg    900×506 封面
└─ portal-preview.png   门户上这张卡片的实拍（仅供核对排版）
```

## 怎么发

```bash
cd origami-studio
./deploy/deploy.sh
```

默认就是 `root@game.sopher.cool:/var/www/game.sopher.cool/origami`，一般不用带参数。可选环境变量：

| 变量 | 作用 |
| --- | --- |
| `DEPLOY_HOST` / `DEPLOY_ROOT` | 目标主机与站点根目录 |
| `DEPLOY_SUBDIR` | 子目录名，默认 `origami` |
| `DRY_RUN=1` | 只演练不写远端（rsync 用 `--dry-run -v`） |
| `SKIP_PORTAL=1` | 只传游戏，不动门户首页 |
| `DEPLOY_SSH_OPTS` | 附加 ssh 参数，例如 `-i ~/.ssh/key` |

脚本做的事：

1. 用 `node --check` 校验 `js/*.js` 语法，并确认封面存在；
2. `rsync -rltz --delete` 把游戏传进 `$DEPLOY_ROOT/origami/`
   （排除 `deploy/`、`tests/`、`tools/`、`README.md`、`SPEC.md`、各 demo 页）；
3. 给 `index.html` 里的 js/css 引用打 `?v=<时间戳>`；
4. 传封面到 `assets/origami-cover.jpg`；
5. 把远端 `index.html` 拉下来 → 本地插卡片 → 远端先备份成 `index.html.bak-<时间戳>` → 覆盖上传；
   内容没变化时自动跳过，不会堆备份；
6. 统一 `chown www-data:www-data` + 目录 755 / 文件 644（**必须做**，否则 nginx 403）；
7. 用 curl 自检 `index.html`、`css/app.css`、全部 `js/*.js`、封面和门户卡片/在架数量。

## 换封面

```bash
# 1. 用无界面 Chrome 截一张 hero：加载页面 → 选图案 → 设折叠程度 →
#    renderer.render() → 隐藏 .topbar/.panel/.foldbar/.toast → page.screenshot()
#    存成 deploy/hero.png（1600×900）
# 2. 生成 900×506 封面（需要 Pillow）
python3 deploy/make_cover.py
# 3. 重新部署
./deploy/deploy.sh
```

## 踩过的坑

- **改了代码但访客看到的还是旧的**：nginx 只给 `.html` 配了 `no-cache`，`.js`/`.css` 没有任何缓存头，
  浏览器会按启发式规则长期用本地副本。现在每次部署都给引用打 `?v=<时间戳>`，页面本身不缓存，必定拉到新脚本。
- **403 Forbidden**：本地文件权限可能是 600，`rsync -a` 会原样带过去，nginx 读不了。
  脚本用 `--no-p --no-o --no-g` 不保留权限，传完统一 chown/chmod。
- **macOS 的 rsync 是 2.6.9**：不支持 `--chmod/--chown`，权限只能传完再用 ssh 修。
- **门户封面用 `loading="lazy"`**：卡片在页面底部，脚本里用 `img.complete` 判断会误报未加载，
  需要先 `scrollIntoView()` 再验证。封面本身 200 + `image/jpeg` 就没问题。
